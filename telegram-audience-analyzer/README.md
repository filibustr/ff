# Telegram Audience Analyzer Bot

Бот для анализа аудитории Telegram каналов, поиска активных пользователей и персонализированной рассылки.

## 📁 Структура проекта

```
telegram-audience-analyzer/
├── app.py                    # Точка входа
├── requirements.txt          # Зависимости
├── amvera.yml               # Конфигурация для Amvera
├── .env.example             # Шаблон переменных окружения
├── .gitignore
└── src/
    ├── bot/                 # Обработчики команд бота
    ├── database/            # Работа с SQLite
    ├── auth/                # Авторизация Telegram
    ├── telegram_client/     # Telethon клиент
    ├── ui/                  # Интерфейс (кнопки)
    ├── analysis/            # AI сегментация
    ├── generation/          # Генерация сообщений
    ├── delivery/            # Рассылка
    └── monitoring/          # Логирование и трекинг
```

## 🚀 Пошаговая инструкция по запуску на Amvera

### Шаг 1: Подготовка аккаунтов

#### 1.1 Telegram Bot Token
1. Откройте @BotFather в Telegram
2. Отправьте `/newbot`
3. Придумайте имя и username для бота
4. Скопируйте полученный токен

#### 1.2 Telegram API Credentials
1. Перейдите на https://my.telegram.org
2. Войдите под своим аккаунтом
3. Нажмите "API development tools"
4. Создайте новое приложение
5. Скопируйте `api_id` и `api_hash`

#### 1.3 OpenAI API Key
1. Перейдите на https://platform.openai.com
2. Создайте аккаунт (если нет)
3. Перейдите в API Keys
4. Создайте новый ключ
5. Скопируйте ключ

### Шаг 2: Регистрация на Amvera

1. Перейдите на https://amvera.io
2. Зарегистрируйтесь через GitHub
3. Установите CLI: `pip install amvera`
4. Авторизуйтесь: `amvera login`

### Шаг 3: Подготовка проекта

```bash
cd telegram-audience-analyzer

# Создайте файл .env
cp .env.example .env

# Отредактируйте .env и вставьте ваши ключи:
nano .env
```

Содержимое .env:
```
TELEGRAM_BOT_TOKEN=ваш_токен_бота
TELEGRAM_API_ID=ваш_api_id
TELEGRAM_API_HASH=ваш_api_hash
OPENAI_API_KEY=ваш_openai_ключ
```

### Шаг 4: Деплой на Amvera

```bash
# Инициализируйте проект
amvera init

# Выберите регион (например, moscow-1)
# Подтвердите создание проекта

# Задеплойте
amvera deploy

# Или через git
git init
git add .
git commit -m "Initial commit"
git remote add amvera <your-amvera-git-url>
git push amvera main
```

### Шаг 5: Настройка mountpoint

В amvera.yml уже настроен mountpoint:
```yaml
mountpoint:
  - path: /data
    volume: data
```

Это обеспечит сохранность базы данных и логов между перезапусками.

### Шаг 6: Проверка работы

1. Откройте вашего бота в Telegram
2. Отправьте `/start`
3. Нажмите "Подключить аккаунт" или отправьте `/login`
4. Введите номер телефона в формате +7XXXXXXXXXX
5. Введите код из Telegram
6. Готово! Аккаунт подключен.

## 📋 Использование

### Главное меню
- **Подключить аккаунт** - авторизация через Telethon
- **Анализ каналов** - добавление каналов для анализа
- **Поиск ЦА** - поиск активных пользователей
- **Рассылка** - отправка сообщений
- **Статистика** - общая статистика

### Добавление каналов
1. Меню → Анализ каналов → Добавить каналы
2. Отправьте username через пробел: `durov telegram pavel_durov`

### Поиск аудитории
1. Меню → Поиск ЦА → Найти аудиторию
2. Бот проанализирует каналы по ключевым словам
3. Сохранит пользователей с score > 30

### Рассылка
- Ограничение: 50 сообщений в день
- Пауза между сообщениями: 30-120 секунд
- Персонализация по имени

## 📊 База данных

SQLite база хранится в `/data/bot.db` и содержит таблицы:
- `users` - пользователи бота
- `channels` - каналы для анализа
- `target_audience` - найденные пользователи
- `segments` - сегменты аудитории
- `messages` - сообщения для рассылки
- `broadcast_history` - история отправок

## ⚠️ Важные замечания

1. **Лимиты Telegram**: 
   - Не более 50 сообщений в день одному пользователю
   - Паузы между сообщениями обязательны

2. **OpenAI costs**:
   - Сегментация: ~100-500 токенов
   - Генерация сообщения: ~50-100 токенов
   - Трекинг затрат ведется в `/data/costs.json`

3. **Безопасность**:
   - Никогда не коммитьте .env файл
   - Session string хранится только в БД

## 🆘 Решение проблем

### Ошибка "FloodWaitError"
Бот автоматически ждет указанное время перед повторной попыткой.

### Ошибка "PeerNotAccessibleError"
Пользователь скрыл профиль или заблокировал бота.

### Ошибка авторизации
Проверьте TELEGRAM_API_ID и TELEGRAM_API_HASH в .env

### Бот не отвечает
Проверьте логи в `/data/logs/bot.log`
